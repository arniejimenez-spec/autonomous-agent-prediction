# V2: order-aware AutoML

## Motivation

V1 scored 0.781 AUC in the competition's black-box outer evaluation versus a 0.803 mean across the sixteen solved tasks. With no trace or per-candidate feedback, v2 makes only changes supported by repeated local evidence.

## Controlled changes

1. String ordinals such as `ord_0`, `ord_1`, and `ord_2` retain their categorical representation and gain a numeric ordered view.
2. Low-cardinality integer/count fields retain their numeric representation and gain a categorical view.
3. A fixed top-two rank blend joins the existing greedy and broad blends.
4. The agent may submit eight precomputed candidates instead of six, still far below the 30-submission limit.

An XGBoost candidate was tested and rejected because its wall-clock cost was disproportionate on ordinal-heavy data.

The improvement is small but broad enough to justify a distinct submission. V1 remains preserved as the fallback baseline.
