# V8.1: Runtime-Safe DGP Portfolio

V8.1 is a harness-reliability correction for v8. The modeling portfolio is unchanged. The submission plan is compact, the modeled submission count is bounded at ten, and final selection occurs immediately.

## Observed failure

The official v8 submission scored 0.500. Because the agent always submits `sample_submission.csv` before modeling, an exact chance-level result is consistent with the fallback remaining as the only usable final prediction.

No official trace was returned, so the exact termination event cannot be proven. The local audit found two new runtime risks in v8:

- the actionable `CANDIDATES` line began 1,000–1,600 characters into command output, compared with roughly 465–1,125 in v7;
- v8 increased orchestration from at most 16 modeled submissions to as many as 28, roughly doubling tool and LLM turns before final selection.

Either output truncation or a hard budget termination could strand the initial fallback.

## Corrections

- Candidate files now use short names: `p01.csv` through `p10.csv`.
- Script stdout contains only `CV_HEDGE`, `CANDIDATES`, and `DONE`.
- Worst-case tested stdout is 135 characters.
- The modeled frontier is capped at ten candidates.
- The full workflow requires at most 14 tool calls: fallback, skill load, script, ten modeled submissions, and final selection.
- `select_submission` is called immediately after candidate submission; the pre-selection status call was removed.
- Model failures remain available in `automl_manifest.json` without consuming command output.

## Evidence

Filtering the completed v8 replay to its first ten CV-ranked candidates preserves the exact selected-private result:

- v7: 0.805604;
- v8: 0.805725;
- v8.1 ten-candidate replay: 0.805725.

Direct fast-mode confirmations also preserve the v8 results:

- `train_16`: 0.913674 selected-private AUC;
- `train_14`: 0.810564 selected-private AUC.

Both runs produced exactly ten candidates and 135 characters of stdout.

## Reproduction

```powershell
.\.venv\Scripts\python.exe scripts/replay_candidate_cap.py `
  submissions/09_meta_routed_automl_v8/meta_results_all.json `

```

An end-to-end local LLM trace requires a configured `.env` and Docker or Podman. Those prerequisites were not present during this correction, so the official validator, direct skill execution, notebook execution, archive inspection, and CI are the available mechanical checks.
