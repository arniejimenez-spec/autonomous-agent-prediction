# V3: adaptive fail-safe AutoML

## Motivation

V2.1 scored 0.814 AUC in the black-box competition evaluation. The 16 solved datasets showed that most remaining opportunity was concentrated in the smaller, harder tasks, while the existing ensemble was already strong on larger datasets.

## Controlled changes

1. Training sets below 4,000 rows receive a smoother depth-4 CatBoost model and a depth-5 CatBoost model using ordered boosting.
2. Training sets of at least 1,500 rows receive cross-validated top-two blend weights of 0.35, 0.50, 0.65, and 0.80; smaller sets use the conservative 0.50 blend.
3. The proven v2.1 blend, top-two blend, and broad blend are always retained as explicit candidates when adaptive models are added.
4. Candidate generation is capped at twelve files, well below the competition's 30-submission limit.
5. The first tool action remains a valid sample-submission call, so a later modeling or orchestration failure cannot produce an empty session.

## Sixteen-task comparison

| Measure | V2.1 | V3 | Change |
|---|---:|---:|---:|
| Mean best-candidate test AUC | 0.802412 | 0.803754 | +0.001342 |
| Mean private AUC after public selection | 0.803195 | 0.804658 | +0.001463 |
| Task outcomes | baseline | 7 wins / 9 ties / 0 losses | no regressions |
| Maximum fast-mode runtime | 229.0 s | 239.7 s | +10.7 s |

The largest gains occur on train_13 (+0.007071), train_16 (+0.007656), train_09 (+0.003181), and train_15 (+0.002896). The complete per-candidate measurements are stored in `submissions/04_adaptive_automl_v3/meta_results_all.json`.

## Submission safety

The agent uses the corrected `/work` path handling introduced in v2.1, invokes the bundled skill with the exact ADK skill API, submits the sample prediction before modeling, and retains the deterministic fallback path. The adaptive models change prediction quality without weakening the submission guarantee.
