# V5: interaction-routed AutoML

## Motivation

V4 matched v3's 0.822 black-box AUC. Selection replay showed that the final pair policy was already within 0.000010 of the available-candidate oracle, so v5 targets a genuinely missing modeling signal rather than further selection tuning.

The v4 portfolio covered linear one-hot effects and interaction-heavy tree ensembles, but it lacked a low-variance model for smooth pairwise numerical interactions.

## Rejected experiment

A spline-expanded logistic model was tested on five numeric and mixed datasets. It produced zero wins: the spline candidate improved over plain logistic on some nonlinear tasks but remained behind the tree portfolio and did not improve the final blend. It was removed completely.

## Quadratic interaction route

V5 adds standardized degree-2 polynomial features with regularized logistic regression when all of these conditions hold:

- 8 to 30 numerical feature views;
- no more than 4 categorical feature views; and
- no more than 30,000 training rows.

Categorical views remain one-hot encoded and are not assigned a false numerical order. The route activates on six solved tasks. It records three wins and three ties with no regressions.

| Dataset | V4 best AUC | V5 best AUC | Change |
|---|---:|---:|---:|
| train_02 | 0.968682 | 0.974777 | +0.006095 |
| train_04 | 0.833694 | 0.834585 | +0.000891 |
| train_16 | 0.913551 | 0.915293 | +0.001742 |

Train_09, train_10, and train_11 retain the exact v4 winner. A boundary test with five categorical views was rejected because it displaced a stronger private hedge on train_01 despite a negligible full-test gain.

## Baseline preservation

Whenever quadratic interactions are enabled, v5 explicitly regenerates v4's greedy blend, broad blend, top-two blend, and weighted top-two blend using only the original v4 model family. This prevents noisy CV ordering from removing a proven candidate.

## Normal-mode confirmation

The agent's first execution path uses four-fold normal mode. Two apples-to-apples controls confirmed both important wins:

| Dataset | Measure | V4 | V5 | Change |
|---|---|---:|---:|---:|
| train_04 | Best test AUC | 0.833959 | 0.834944 | +0.000985 |
| train_04 | Selected-pair private AUC | 0.833973 | 0.835231 | +0.001259 |
| train_16 | Best test AUC | 0.912654 | 0.914976 | +0.002322 |
| train_16 | Selected-pair private AUC | 0.910751 | 0.912741 | +0.001990 |

Normal-mode modeling elapsed 70 seconds on train_04 and 130 seconds on train_16, comfortably within the 60-minute session limit.

## Submission safety

V5 retains the first-call sample submission, persistent `/work` handling, exact ADK skill calls, deterministic recovery modes, top-two-public selection, candidate cap, and final `get_status` check. No solution data or test labels are bundled into the agent.
