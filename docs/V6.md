# V6: Carefully Routed Tree Diversity

V6 adds XGBoost and Random Forest as diversity candidates without making either model mandatory. The complete v5 model family is reconstructed whenever a v6 tree model is active, so the public-score selector can retain the validated baseline.

## Routes

- Random Forest: 1,000 to 12,000 training rows.
- XGBoost: 4,000 to 15,000 training rows and at least five categorical feature views.
- XGBoost uses median-imputed numeric features and sparse one-hot categorical features.
- Random Forest uses the same imputed ordinal representation as ExtraTrees, but with bootstrap aggregation, balanced subsampling, a broader feature fraction, and stronger leaf regularization.

The routes are separate because the solved-task evidence showed Random Forest adding useful diversity on both numeric and categorical tasks, while XGBoost paid off primarily when categorical structure was substantial.

## Evidence

Fast-mode route discovery and confirmation produced selected-private improvements on `train_06`, `train_07`, and `train_09`, with neutral selected-private outcomes on `train_04`, `train_05`, `train_08`, and `train_16`. The composed 16-task replay changed:

- mean best-test AUC: 0.804320 to 0.804391;
- top-two-public best-private AUC: 0.805363 to 0.805450;
- confirmed routed regressions: zero.

A normal four-fold run on `train_07` selected a v6 pair with 0.834534 private AUC. The best preserved v5-family candidate in the same run reached 0.832652.

## Runtime and safety

Both optional models are imported defensively. If XGBoost is unavailable, the remaining portfolio still runs. `--fallback` keeps the lightweight Random Forest recovery path. The agent still submits `sample_submission.csv` first, produces at most sixteen modeled candidates, and selects exactly the two highest public scorers.
