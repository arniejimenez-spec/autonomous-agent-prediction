# V7: Fingerprint-Routed Specialists

V7 changes the decision system rather than adding another globally active model. It computes train-only fingerprints from dataset size and prepared feature geometry, routes specialists only to matching archetypes, and reserves one final slot for an exact historical baseline when the specialist portfolio is active.

## Routes

- Medium categorical profile: 4,000–15,000 rows and at least five categorical views. Add shallow depth-4 and ordered depth-5 CatBoost variants.
- Tiny high-dimensional categorical profile: at most 1,000 rows and at least ten categorical views. Add a cross-fitted target-encoded logistic model plus fixed 20% and 35% target-encoding blends.
- Existing v6 Random Forest and XGBoost routes remain unchanged.

The target encoder is fitted inside each outer training fold, so validation rows and test rows never contribute labels to their encodings.

## Safe selection

V7 reconstructs exact v5 and v6 candidate families and marks equivalent files. A pilot-CV rule prefers the v6 hedge on all-categorical tasks or when XGBoost CV matches or beats depth-6 CatBoost; otherwise it prefers v5. The script prints the highest-CV candidate from that family after `SAFE_HEDGE`.

The final pair is:

1. the highest public scorer;
2. the printed safe hedge, or the second-highest public scorer if the hedge already leads.

Public feedback selects only among precomputed predictions and never alters prediction values.

## Evidence

The composed fast-mode replay across all sixteen solved tasks improves the frontier-plus-hedge selected-private mean:

- v6: 0.805450;
- v7: 0.805604;
- routed selected-private regressions: zero.

The largest fast-mode improvement is train_15, from 0.864892 to 0.867074. A normal four-fold confirmation reaches 0.868734, compared with 0.866506 for the exact safe baseline in the same run.

## Reproduction

`scripts/analyze_fingerprint_router.py` creates the train-only fingerprint table. `scripts/replay_v7_policy.py` replays the final two-slot policy using `policy_hedges.json`. All solved-task labels remain outside the packaged agent.
